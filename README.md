# 无限传送背包：不炸、不伤、不涨热

让 **LIFT-182 传送背包**变得安全：不再自爆、不再自伤、每次传送不再累积热量。

## 改动

| 项目 | 原版 | 修改后 |
|---|---|---|
| 爆炸类型 | 254 | **0（ExplosionType_None，无爆炸）** |
| 每次传送热量 | 33.0 | **0（不涨热）** |
| 传送距离 | 原版 | **10 米** |

## 效果说明

- **不炸**：传送落点不再产生爆炸，因此不会自伤，也不会伤到队友
- **不涨热**：连续传送不会因为热量累积而进入过热状态
- **10 米**：传送距离设为 10 米

## 依赖

**只需要 Bingus Shared Loader v15 及以上**（或兼容的新版本）。无其他前置，下载即用。

## 安装

把 ZIP 导入 Arsenal / HD2 Mod Manager，启用后部署，彻底退出游戏再重新启动。
Loader 放到列表最后（若开启「首个 mod 优先」则放最前）。

## 版本与适配

- 当前版本：`0.1.0`
- 目标游戏构建：**25327279**

本 mod **不校验游戏构建号**，改为在写入前逐字段核对原始字节：一旦游戏数据不匹配，会返回 `warp_map_entry_mismatch` / `field_mismatch` / `row_mismatch` 并**直接拒绝写入**，不会强行覆盖。

游戏更新后可能失效，届时需要重新适配。

## 日志

```
%LOCALAPPDATA%/CowboyBingus/Helldivers2/Logs/WarpPackSafe.log
```

写入成功会记录 `warp_safe_applied fields=… explosion=none heat_gain=0 range=10m`。

## 注意

内存模组属客户端运行时改动，联机表现可能与队友不一致，并存在反作弊风险。建议仅在知情固定队环境中使用。
